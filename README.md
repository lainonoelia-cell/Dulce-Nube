# Dulce Nube ☁️🍦

Dulce Nube es un sitio web de una heladería y confitería ficticia, desarrollado como proyecto de Pre-Entrega para el curso de Front End JavaScript de Talento Tech.

La página presenta diferentes productos de la tienda, una sección de reseñas y una página de contacto con formulario funcional mediante Formspree.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox 
- CSS Grid
- Media Queries
- Google Fonts
- Formspree
- Git y GitHub
- GitHub Pages

## Estructura del proyecto

- `index.html`: página principal con los productos.
- `pages/contacto.html`: formulario de contacto.
- `css/styles.css`: estilos del sitio.
- `img/`: imágenes utilizadas en el proyecto.
